How the Solver Works

A behind-the-scenes look at the algorithm that solves every Boxman level — and plays them back-to-back in Speed Run.

It doesn't "see" the board — it searches a space of states

The solver doesn't reason about pixels, sprites, or the puzzle visually the way you do. It reduces every level to a plain fact: a state is the player's position plus the exact set of box positions. Two states are "the same" if every box is in the same place and the player is standing in the same cell — nothing else about the board matters.

Solving the puzzle becomes a graph problem: starting from the level's initial state, explore every state reachable by one move (up/down/left/right — pushing a box if one is in the way), then every state reachable from those, and so on, until a state is found where every target has a box sitting on it.

Breadth-first search: try everything, one layer at a time

This is breadth-first search (BFS). It explores states in layers — first every state reachable in 1 move, then in 2 moves, then 3 — never skipping ahead. The moment a winning state turns up, the search stops, and because every state one layer out is reached before any state two layers out, the first solution found is guaranteed to be the shortest possible one, measured in player moves.

Why not just try random moves, or push boxes greedily toward targets? Sokoban is notoriously deceptive — a box pushed into the wrong corner can be stuck forever, and the correct first move is often not the one that looks like progress. BFS doesn't guess; it exhaustively rules out nothing until it finds what actually works.

Why some levels are so much harder

Every extra box roughly multiplies the number of possible arrangements, so the state space grows combinatorially, not linearly. A level with 3 boxes might have a few thousand reachable states; a level with 8 boxes can have millions. Why Speed Run doesn't search live for every level

The in-game Solve button caps its live search at 300,000 states so the browser tab never freezes waiting on it. That's plenty for most levels — but four of them (8, 10, 12, and 14) need well over a million states to crack, and one of them took nearly two minutes of dedicated searching offline to solve at all. Running that live, on every level, every time Speed Run plays, would mean sitting through minutes of a frozen page.

Instead, the exact winning move sequence for all 15 levels was solved once, offline, with no time pressure — the same BFS algorithm shown above, just given as long as it needed. Speed Run replays those known solutions instantly. If you've already made moves of your own on a level, though, Solve still falls back to a live search from wherever you actually are.
